# Borne vers Maps, version auto-hébergée

Contenu: index.html (application complète), manifest.webmanifest, sw.js (cache hors-ligne), icon-180.png.

Déploiement en HTTPS obligatoire (le service worker et le partage exigent HTTPS):
1. GitHub Pages: pousser ces 4 fichiers à la racine d'un dépôt, activer Pages sur la branche main.
2. Ou Netlify / Cloudflare Pages: glisser-déposer le dossier.

Sur iPhone: ouvrir l'URL dans Safari, bouton Partager, "Sur l'écran d'accueil".
